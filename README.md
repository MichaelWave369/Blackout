# BLACKOUT

**Wake up. Blood on your hands. No memory. No alibi. No time.**

A retro-first, VR-bound 1947 Chicago noir mystery starring private investigator Vincent Morrow.

## Development
The first playable milestone is **Blood on the Mirror**, a browser-based detective prologue inspired by the *feel* of classic point-and-click adventures. BLACKOUT uses original story and presentation, not third-party game assets.

- Retro playable vertical slice: hotel bathroom, room 214, and escape.
- Clues, inventory, memory fragments, moral choices, and a detective notebook.
- Cross-platform investigation state intended for future WebXR / Quest 3 adaptations.
- Offline-capable static web deployment through GitHub Pages.
